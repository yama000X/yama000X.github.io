yt-tool プライバシーポリシー

制定日: 2026年10月28日

1. このツールについて

yt-tool は、運営者本人だけが使う個人用のツールです。YouTube API サービスを使って、運営者自身の YouTube チャンネルへの動画の予約投稿と、運営者自身の動画へのコメントの書き込みだけを行います。

2. 取得する情報

運営者本人が許可した、運営者自身の YouTube アカウントへのアクセス権（OAuth のトークン）だけを扱います。運営者以外の人の情報は取得も保存もしません。

3. 情報の使い方と保存

トークンは運営者のパソコンの中にだけ保存し、上の目的のほかには使いません。第三者に提供したり販売したりしません。

4. 許可の取り消し

許可は、Google アカウントのサードパーティによるアクセスからいつでも取り消せます。

5. YouTube API サービス

このツールは YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーも適用されます。

6. 変更

内容を変えるときは、このページを更新します。
